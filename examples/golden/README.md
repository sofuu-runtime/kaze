# Example traces

The active golden tests cover local logging, policy decisions, and explicitly
selected drone simulation. Drone traces are labelled as simulation.

The older `greenhouse.txt`, `guardrail.txt`, `modular.txt`, and `rover.txt`
files are historical snapshots, not current runnable examples or evidence of
real sensor, memory, alert, or device operations. Those examples now refuse
when the required real backend is unavailable.
